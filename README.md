BeatSound is a simple 2D endless runner game made using HTML, CSS, and JavaScript. The goal is to avoid obstacles, collect coins, and achieve a high score.

## Features
- Double jump
- Obstacles and collision detection
- Coin collection
- Score and combo system
- Sound effects and background music
- Increasing difficulty

## Controls
- `SPACE` - Jump
- `SPACE` twice - Double jump
- `R` - Restart after game over

## Technologies Used
- HTML
- CSS
- JavaScript
- Canvas API

## How to Run
1. Visit: https://gregarious-ganache-21d3cf.netlify.app/
2. Open `index.html` in your browser.
